Joakim's drawings go here. Every drawing the game can use already has a file here: a copy of its template (see
../WANTED.md). Open one in Paint.NET, draw on a new layer, hide the grid layer, and save over it with the same name.
Untouched copies are ignored, so the game keeps drawing that thing in code until you've drawn it.
Push, and it's on joakimskar.no about two minutes later.
